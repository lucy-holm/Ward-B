# Fonts

Both are freely licensed for embedding in a commercial game. Do not replace
them with system fonts — macOS/Windows system faces are not redistributable,
and a web export cannot rely on the host having them anyway.

| File | Family | Licence | Used for |
|---|---|---|---|
| `RockSalt-Regular.ttf` | Rock Salt | Apache 2.0 | wall scrawls — rough hand-marker, reads as something written by a patient rather than set by a computer |
| `SpecialElite-Regular.ttf` | Special Elite | Apache 2.0 | institutional signage (door plates, MEDICATION, STAFF ACCESS) — distressed typewriter, reads as ward paperwork |

Source: https://github.com/google/fonts
